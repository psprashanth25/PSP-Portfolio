## ✨ Interactive Hero Experience

The hero section features a **cute, relatable, and visually spectacular 3D developer environment** engineered with Three.js and custom CSS:

- **3D Developer Studio Scene**: Warm, cozy Pixar/Blender-inspired developer studio featuring a software engineer at a curved desk with wireless headphones.
- **Directly Engraved "PSP" Ceramic Cup**: Foreground ceramic coffee mug with **`PSP`** realistically engraved into the cylindrical ceramic surface with authentic 3D depth and specular reflections.
- **Depth & Mouse Parallax**: Three.js `PerspectiveCamera` with smooth spring-damped lerp physics tracking cursor position to create real visual depth without figure distortion.
- **Dynamic Three.js Lighting**: Dual dynamic point lights (electric cyan `#38bdf8` and vibrant magenta `#e879f9`) with sinusoidal breathing cycles that realistically illuminate the workspace.
- **Cute Floating AI Companion Robot**: Interactive bot hovering near the monitor with bobbing physics and glowing cyan eyes; hovering triggers an interactive greeting (*"Hi Prashanth! Ready to code? 🚀"*).
- **Curved Ultrawide Monitor Live Telemetry**: Continuous active syntax marquee stream displaying real-time developer metrics and pipeline commands.
- **Volumetric 3D Starlight Particles**: 280 twinkling particles in Three.js floating gently in space with sinusoidal orbital motion.
- **Clean High-Contrast Typography Zone**: Distraction-free left wall framed by warm string fairy lights, ensuring optimal readability and contrast for hero headlines and CTAs.
- **Custom Companion Drone Cursor ("Agi")**: Follows the mouse with banking turns based on velocity; digital visor eyes blink naturally and transform into happy arcs (`^ ^`) over interactive elements; click events emit expanding cyber shockwaves and floating tech micro-sparks (`✦`, `{ }`, `<`, `>`).

## 💻 Local Development & Setup

### Prerequisites
- **Node.js**: Version `20.x` or later (tested on Node v24)
- **npm**: Version `10.x` or later

### Installation
Clone the repository and install the dependencies:
```bash
git clone https://github.com/psprashanth25/PSP-Portfolio.git
cd PSP-Portfolio
npm install
```

### Start Development Server
```bash
npm run dev
```
The local server will start at `http://localhost:3000`.

### Typecheck
```bash
npm run typecheck
```

### Build for Production
```bash
npm run build
```
Generates an optimized production bundle in the `dist/` directory with vendor code-splitting (`vendor-three`, `vendor-react`, `vendor-icons`).

### Preview Production Build
```bash
npm run preview
```
